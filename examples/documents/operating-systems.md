# Operating Systems

Operating systems manage computer hardware and provide services to applications.

## Processes

A process is a program in execution.

### Process States

A process can be in states such as new, ready, running, waiting, and terminated.

## Memory Management

Memory management controls how memory is allocated to processes.

### Virtual Memory

Virtual memory allows a system to use disk space as an extension of physical memory.

### Paging

Paging divides physical memory into fixed-size blocks called frames and logical memory into pages.

## File Systems

A file system organizes and stores files on storage devices.

### File Allocation

File allocation determines how files are stored on disk.
